# Cybersecurity Portfolio

## Overview
This is a modern, responsive portfolio website for Ahammed Zidan M, showcasing skills, projects, and experience in the field of cybersecurity. The website is designed with a dark theme featuring black and neon blue accents, ensuring a clean and modern user interface.

## Project Structure
```
cybersecurity-portfolio
├── src
│   ├── css
│   │   └── styles.css
│   ├── js
│   │   └── scripts.js
│   ├── index.html
├── assets
│   ├── fonts
│   └── icons
├── README.md
```

## Features
- **Responsive Design**: The website adapts to various screen sizes, ensuring a seamless experience on both desktop and mobile devices.
- **Smooth Scrolling Navigation**: Users can navigate through sections smoothly, enhancing usability.
- **Animated Effects**: Subtle animations provide a modern touch to the user interface.
- **Contact Form**: Users can reach out through a functional contact form.
- **Download CV Button**: A feature allowing visitors to download Ahammed's CV.

## Setup Instructions
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd cybersecurity-portfolio
   ```
3. Open `src/index.html` in your web browser to view the portfolio.
